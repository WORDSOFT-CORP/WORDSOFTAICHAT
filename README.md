# WORDSOFT AI Chat

Простой веб-клиент в стиле интерфейса GPT Chat для общения с моделью Gemini. Интерфейс поддерживает многоразовый диалог и загрузку изображений для мульти-модальных запросов.

## Быстрый старт

Откройте `index.html` в браузере. В интерфейсе доступны:

- отправка текстовых сообщений;
- загрузка изображения (до 4 МБ) с отображением превью в чате;
- отображение индикатора ожидания ответа модели;
- контекстный диалог на основе истории переписки.

> ⚠️ Обратите внимание, что API-ключ модели жестко зашит в клиент и при публикации в открытом доступе его следует заменить на защищённый способ хранения.
